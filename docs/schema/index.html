Schema Files

  • club-metadata.schema.json Sidecar club identity metadata keyed by clubId. Records combine source-backed history with generated observations from the season tables. view raw
  • football-data.schema.json Merged English football season dataset. Season records contain a seasonInfo summary and zero or more tierN league-table records. view raw
