# v0.5.0

## Summary

- Initial release of cleaned English league-table data covering `1888-2024`.
- Added dual-source Wikipedia scraping for pre-Premier League and post-Premier League page formats.
- Added resumable CLI tooling and release automation for publishing the data package.

## Breaking Changes

None. This was the initial public release.

## Data Changes

- Published `all-seasons.json` and minified data for merged tier 1+ tables across the Football League and Premier League eras.
- Published `wiki_promotion_relegations_by_season` outputs for the raw promotion/relegation scraper, described in the original release notes as best for `1888-1990`.
- Published `wiki_overview_tables_by_season` outputs for overview-table scraping, described in the original release notes as reliable from `1991` onward.

## Bug Fixes

None recorded in the GitHub release notes.

## Validation

- Added CI unit and lint checks on every push.
- Added twice-weekly Wikipedia integration tests.
- Added a release workflow that rebuilds data and publishes the release zip automatically.
- The original release notes recommended running `node scripts/verify-football-data.js --fail-on-issues ./data-output` after generating new data to catch empty seasons, duplicate teams, or stat mismatches.

## Consumer Notes

- This was the first published data package.
- Later releases changed the maintained workflow and validation surface; prefer the latest release for current use.

## Known Limitations

- The original notes described the data as cleaned but still early.
- Overview-table scraping was described as reliable from `1991` onward, while promotion/relegation output was described as best for `1888-1990`.
