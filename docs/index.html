What is this?

A small data kit for English football history: league tables by season, promotion and relegation summaries, and a sidecar file for club identity metadata.

The maintained dataset is generated from Wikipedia overview pages, validated by local checks, and committed as static files for direct download.

Schema

schema index

Human-readable JSON Schema references for the published data files.

  • club-metadata.schema.json Sidecar club identity metadata keyed by clubId. Records combine source-backed history with generated observations from the season tables. view raw
  • football-data.schema.json Merged English football season dataset. Season records contain a seasonInfo summary and zero or more tierN league-table records. view raw
